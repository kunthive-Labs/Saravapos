The idea

The facts are sound. The mental model is missing.

A chess coach says "sacrifice a pawn for positional advantage" and another chess player nods — but a Formula 1 fan hears empty noise. The information is correct; the metaphor it's wrapped in just doesn't land.

Saravapos closes that gap. You describe a person's worldview — their expertise, preferred analogies, cognitive style and cultural references — as a small YAML profile. Given a from profile and a to profile, it rewrites content so the metaphors translate while the underlying facts stay intact. It's a protocol first: a JSON Schema defines what a profile is, so anyone can implement against it.

Highlights

What's in the box

Concrete, shipped capabilities — every one backed by code in the monorepo.

Protocol-first

A frozen 0.1 JSON Schema (@saravapos/spec) defines what a persona profile is. Implement a conforming translator in any language.

Local-first ownership

Profiles are plain YAML files you own and edit. No accounts, no servers, no telemetry — the data never leaves your machine.

Multi-provider adapters

Bring your own LLM key. First-class adapters for Anthropic, OpenAI and local Ollama, resolved at runtime.

CLI & SDK

Use saravapos from the terminal — init, validate, translate — or call loadProfile / translate from @saravapos/sdk in Node.

Eval harness & quality gate

Golden cases scored by an LLM judge plus lexical checks. A CI gate enforces a corpus mean ≥ 3.5 and tracks regressions against a baseline.

Swappable prompt strategies

Pick the rewriting approach — structured, fewShot, analogyFirst, dynamicAnalogy and more — with an eval compare A/B scorecard.

The pipeline

How the protocol works

Two profiles in, faithful translation out — in four steps.

1

Author profiles

Describe each worldview as YAML: expertise, an analogy_bank, cognitive style and cultural context. saravapos init scaffolds one.

2

Validate

Run saravapos validate to check the profile against the frozen 0.1 schema before you use it.

3

Resolve an adapter

Pick a provider — Anthropic, OpenAI or Ollama — and supply your own key via an env var. No vendor lock-in.

4

Translate

Pass --from and --to profiles with your text. The chosen prompt strategy injects matching analogies and rewrites — facts preserved.

Get started

Quickstart

Install the CLI, author a profile, and translate your first sentence.

bash 
# install the CLI globally (requires Node 20+)
npm install -g @saravapos/cli

# author a profile interactively
saravapos init --output me.yaml

# validate it against the schema
saravapos validate me.yaml

# translate something — bring your own key
export ANTHROPIC_API_KEY=sk-...
saravapos translate \
  --from profiles/chess-expert.yaml \
  --to   profiles/f1-fan.yaml \
  --text "I sacrificed a pawn for a positional advantage"

Prefer code? Add the SDK with pnpm add @saravapos/sdk @saravapos/adapters and call translate() directly.
