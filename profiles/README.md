# Sample Profiles

Hand-authored worldview profiles used for development, testing, and dogfooding.

| File                     | Persona           | Strong domain                 | Weak domain           |
| ------------------------ | ----------------- | ----------------------------- | --------------------- |
| `chess-expert.yaml`      | Chess Expert      | chess (expert)                | formula-one (novice)  |
| `f1-fan.yaml`            | F1 Fan            | formula-one (expert)          | chess (novice)        |
| `software-engineer.yaml` | Software Engineer | software-engineering (expert) | —                     |
| `curious-novice.yaml`    | Curious Novice    | everyday-life (expert)        | all technical domains |

Each profile validates against the `@wv/spec` schema. See `docs/spec.md` for field semantics.
